# 古典単語DX v3.0 — 古典常識モード追加

スマートフォン・PC向けの古典学習アプリ。GitHub Pagesで公開できる静的サイトです。

## 学習内容

- 重要古語 **353語**（単語カード・意味4択）
- 文脈演習 **135問**（学習用オリジナル例文）
- 文法・文学史・漢文など **152問**
- **新・古典常識 175問（12分野）**：宮中・身分／住居・調度／装束・美意識／恋愛・婚姻／和歌・表現／暦・時刻／年中行事／信仰・死生観／旅・交通／儀礼・人生／文学・ジャンル／生活・芸能

**合計815の練習パターン**。古典常識は専用モードから難易度・分野・出題数で絞り込めます。

## 主な機能

単語カードの反復復習、4択、文脈問題、文法ミニ演習、古典常識、単語検索、ブックマーク、間違いの復習、学習記録バックアップ、オフライン対応設計。

## GitHub Pagesで更新する手順

1. このZIPを解凍し、**中のファイル**を既存の `koten-tango-dx` リポジトリのトップ階層へ置く。
2. 同名ファイル `index.html`, `app.js`, `style.css`, `data.js`, `data.json`, `sw.js` などを更新する。
3. Settings > Pages が `main / (root)` になっていることを確認する。
4. ブラウザで新しい古典常識モードが表示されるか確認。古い版が表示される場合は再読み込みする。オフラインキャッシュはv3に更新済み。

**学習記録は以前と同じ localStorage キーを使用**し、更新時に消去しません。ただし同じ端末・同じサイトのURLである必要があります。

## 品質・出典

新規175問は1問ごとにオリジナルの四択と解説を作成し、問題ID・選択肢重複・正答番号を自動検査。`CULTURE_QUESTIONS.csv` で全設問を確認できます。文法・語彙の既存データは原則そのまま引き継いでいます。各古語・歴史的事実を独立した辞典や資料と一件ずつ照合した完全監修版ではありません。`SOURCES.md` と `AUDIT.md` を参照してください。
